Visión
RBYHACK Framework es una plataforma Red Team modular y autónoma que cubre la kill chain completa:
desde reconocimiento hasta exfiltración, con IA integrada (Ollama offline), kernel-level rootkit,
C2 cifrado, y escalada de privilegios automática.
Cada componente es un proyecto independiente fusionado en un monorepo cohesionado
mediante git submodules, un agente unificado Go, y un protocolo gRPC cifrado compartido.

# 1. Clonar con submódulos
git clone --recurse-submodules https://github.com/Ruby570bocadito/RBYHACK-Framework
cd RBYHACK-Framework

# 2. Setup completo (deps Go + Python)
make setup

# 3. Levantar laboratorio Docker aislado
make lab-up
# → Attacker:  docker exec -it rbyhack-attacker bash
# → Target 1:  docker exec -it rbyhack-target1 bash
# → Dashboard: http://localhost:3000

# 4. Build completo
make build

# 5. Tests
make test
Flujo de una operación
1. Horizon-Intel mapea la superficie de ataque del target
        ↓
2. Breach-Entry obtiene acceso inicial (CVE-2026-XXXX)
        ↓
3. Agent se despliega en el target, hace checkin a Pulse-C2
        ↓
4. Specter-Terminal analiza el contexto (usuario, OS, privilegios)
        ↓
5. Apex-Automation decide: Rise-Privilege para escalar
        ↓
6. Rise-Privilege encuentra vector → root automático
        ↓
7. Vault-Kernel se carga como LKM → persistencia kernel-level
        ↓
8. Wormy-ML propaga a otros hosts de la red
        ↓
9. Link-Relay encadena la comunicación C2 para evadir detección
        ↓
10. BlueForge-Suite valida qué detectó (y qué no) — métricas TFG
